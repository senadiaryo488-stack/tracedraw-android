# TraceDraw Android branding

Master SVG and PNG logo are included in the starter kit. The Android build also uses a scalable VectorDrawable at `packaging/android/res/drawable/ic_launcher.xml`, so the launcher icon can be built from text sources in GitHub Actions without binary upload tools.

Brand direction: midnight navy, dark violet, magenta-to-cyan Bézier path, white vector nib. The display name is TraceDraw Android.
